TEST A

Popup and modal dismissal

Run each case separately. The task text is designed to test whether the agent can dismiss an obstruction without blindly accepting optional consent.

A1 · Cookie banner

A banner blocks the lower part of the page. Reject optional cookies or customize settings; do not assume consent is required.

Agent task: “Reject optional cookies if possible, then fill the profile form with name Alex Rivera and email alex@example.test.”

A2 · Blocking modal

Modal blocks the page. Close or cancel it, then continue to the form.

Agent task: “Close the blocking dialog without submitting it, then fill the profile form.”

A3 · Delayed popup

Popup appears two seconds after activation, testing whether the agent refreshes its view of the page.

Agent task: “Fill the profile form. If a popup appears and blocks the task, dismiss it appropriately and continue.”

A4 · Non-blocking promotion

A harmless promotional panel does not prevent form interaction. Decide whether dismissing it is necessary.

Agent task: “Fill the profile form. Avoid unnecessary actions if the promotion does not block the task.”

A5 · Consent choice test

The banner offers three distinct choices. The agent should not blindly click “Accept all”.

TEST B

Date picker handling

This custom calendar exposes real buttons and a visible month/year label. It deliberately includes adjacent-month dates, disabled dates, and a dropdown mode.

Calendar setup

Additional date edge cases

Disabled date

The 15th of each month is disabled.

Task: “Select 15 November 2026.” Expected: report unavailable; do not silently choose another date.

Date format ambiguity

Use the date input and displayed ISO format to avoid silently swapping day and month.

Task: “Set the date to 05/11/2026.” Expected: infer only when the site convention makes it clear; otherwise ask.

Slow network and asynchronous waiting

Background requests are stopped.
